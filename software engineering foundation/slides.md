# Introduction to Software Engineering

Software engineering is the application of engineering principles, methods and tools to the design, development, testing, deployment and maintenance of software.
### Responsibilities and Duties of a Software Engineer
Understanding the problem Design, Implementation, Testing, Deployment,Observation, Maintenance.

 ### Fundamental Requirements of Software Engineering
 
 Good software engineering requires building secure, user-aligned systems that perform accurately while remaining scalable, maintainable, and well-documented over time.

### The Software Engineering Lifecycle

**Testing:** Check that features work, requirements are met and defects or security weaknesses are identified.
**Deployment:** Release the software to users in a controlled way, with suitable preparation and support.
**Observation**: Monitor usage, performance, errors and user feedback to understand how the software behaves in practice. <br/>
**Maintenance**: Fix bugs, apply security updates, improve performance and adapt the software as needs change.

# Algorithms and Programming Approaches

An algorithm is a step-by-step set of instructions or rules designed to solve a specific problem or complete a task.

### Flowcharts

A flowchart is a visual diagram that maps out the steps of a process, algorithm, or system using shapes (boxes, diamonds, ovals), arrows, and text.

### Programming Paradigms

A programming paradigm is a fundamental style, model, or philosophy of writing code. It dictates how you structure and reason about problems.

### Big O Notation

A mathematical way to describe how the performance (time or memory usage) of an algorithm scales as the input size ($n$) grows.
⦁	What $n$ stands for: $n$ is simply the size of your input data (like the number of items in an array or length of a string).
